# 10 — 이탈리아 지도 기반 지역 선택 + 정보 팝업

## Outcome

"꼭 가고 싶은 지역"을 이탈리아 지도 위 도시 마커로도 볼 수 있다. 마커를 클릭·터치하면 그 도시의 대표 이미지 몇 장과 간단한 설명이 팝업으로 뜨고, 동시에 그 도시가 "꼭 가고 싶은 지역" 선택에 토글된다. 기존 체크박스 목록과 지도는 같은 선택 상태를 공유한다.

## Blockers

None.

## Acceptance criteria

- [ ] 큐레이션 도시 각각이 이탈리아 지도 위의 좌표에 맞는 위치에 클릭·터치 가능한 마커로 표시된다.
- [ ] 마커를 클릭·터치하면 그 도시의 대표 이미지 몇 장(최소 2장)과 간단한 설명이 담긴 팝업이 뜬다.
- [ ] 팝업이 뜸과 동시에 그 도시가 "꼭 가고 싶은 지역" 체크박스 목록에서 선택/해제된다(이미 선택된 도시를 다시 클릭하면 해제). 최대 선택 개수 제한(`MAX_VIA_CITIES`)은 지도 클릭에도 그대로 적용된다.
- [ ] 체크박스 목록에서 선택/해제하면 지도 위 해당 마커의 선택 표시(예: 강조 색)도 함께 바뀐다.
- [ ] 도착 도시·출발 도시로 지정된 도시는 기존 체크박스 목록과 마찬가지로 지도에서도 선택 대상 마커로 다루지 않는다(정보 팝업은 볼 수 있어도 선택 토글은 되지 않거나, 목록에서 제외된 것과 일관되게 동작한다).
- [ ] 큐레이션 목록에 없는 지역/도시는 지도 위에 클릭 가능한 마커로 나타나지 않는다.
- [ ] 팝업에 쓰이는 이미지가 깨지면 팝업 자체는 계속 보이고 이미지 자리에는 대체 표시가 나온다(기존 맛집·관광지 이미지 깨짐 처리와 동일한 패턴).

## Constraints

- 지도는 실시간 지도 API를 불러오지 않고, `lib/travel-data.ts`의 큐레이션 좌표(lat/lng)를 화면 좌표로 환산해 그리는 정적 SVG(또는 이에 준하는 좌표 기반 벡터)로 구현한다.
- 도시별 대표 이미지·설명은 새 큐레이션 정적 데이터로 준비하며, 이미지는 기존과 같이 무료/오픈 라이선스 이미지를 쓴다.
- 모바일 터치와 데스크톱 클릭 모두 동작해야 한다.

## Verification

- 마커 클릭 시 팝업 노출과 선택 상태 토글이 함께 일어나는지, 체크박스 목록과 지도의 선택 상태가 항상 일치하는지 테스트.
- 큐레이션 목록에 없는 값이 마커로 나타나지 않는지 확인.
- 이미지 URL이 깨졌을 때 팝업 안 대체 표시가 나오는지 확인.
