# 14 — 전체 화면 비주얼 디자인 리프레시

## Outcome

기능 변경 없이, 화면 전체(제목/헤더, 여행 플래너, 지도, 내 위치 주변 정보, 일자별 일정, 체크리스트, 예산 트래커)의 시각적 완성도를 학습용 데모(POC) 느낌을 벗어나는 수준으로 다듬는다. 제목 영역은 눈에 띄게 꾸며진 히어로 형태로 바뀐다.

## Blockers

None.

## Acceptance criteria

- [ ] 페이지 제목 영역이 단순 텍스트 헤더가 아니라 눈에 띄는 히어로 섹션(부제/설명 문구, 시각적 강조 등 포함)으로 바뀐다.
- [ ] 여행 플래너, 지도, 내 위치 주변 정보, 일자별 일정, 체크리스트, 예산 트래커 섹션이 일관된 색상·타이포·여백·카드 스타일을 공유한다.
- [ ] 라이트/다크 모드 모두에서 텍스트 대비와 레이아웃이 깨지지 않는다(기존 다크 모드 지원 유지).
- [ ] 모바일 폭에서도 레이아웃이 깨지지 않고 주요 정보(제목, 폼, 지도, 리스트)가 읽기 가능한 순서로 배치된다.
- [ ] 기존 기능(입력, 루트 계산, 내보내기, 공유, 체크리스트, 예산 계산)의 동작은 이번 태스크로 바뀌지 않는다.

## Constraints

- 새 UI 라이브러리나 외부 CSS 프레임워크를 추가하지 않고, 기존 Tailwind 유틸리티 클래스와 `components/ui`의 기존 컴포넌트 패턴을 확장하는 선에서 구현한다.
- 09~13번 태스크에서 새로 추가되는 지도·후보 리스트·이미지 UI도 이 디자인 톤(카드 스타일, 색상, 타이포)을 따른다. 이 태스크는 09~13번과 병행하거나 이후에 진행할 수 있으며, 어느 순서로 하든 최종 화면은 하나의 디자인 톤으로 수렴해야 한다.
