# 11 — 추천 루트 지도 시각화

## Outcome

추천 루트가 계산되면, 그 루트의 방문 순서(도착 도시 → 경유 도시들 → 출발 도시)가 10번 태스크에서 만든 이탈리아 지도 위에 경로(선 등)로 겹쳐 표시된다.

## Blockers

10-region-map-with-info-popup — 경로를 그릴 지도 컴포넌트가 먼저 있어야 한다.

## Acceptance criteria

- [ ] 추천 루트가 없을 때(입력 미완/오류)는 지도 위에 경로가 표시되지 않는다.
- [ ] 추천 루트가 계산되면, 루트에 포함된 도시들이 방문 순서대로 지도 위 선으로 연결되어 표시된다.
- [ ] 루트를 구성하는 도시 마커는 다른 큐레이션 도시 마커와 시각적으로 구분된다(예: 순서 번호 표시나 강조 색).
- [ ] "꼭 가고 싶은 지역" 선택을 바꿔 루트가 다시 계산되면, 지도 위 경로도 새 루트에 맞게 갱신된다.

## Constraints

- 10번 태스크와 같은 정적 좌표 기반 지도 위에 그린다. 별도의 지도 컴포넌트를 새로 만들지 않는다.

## Verification

- 루트 없음 → 경로 없음, 루트 있음 → 방문 순서대로 이어진 경로가 표시되는지 테스트.
- 루트가 바뀌었을 때(경유 도시 변경) 경로도 갱신되는지 확인.
