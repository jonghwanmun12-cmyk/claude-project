# 나폴리·베로나 큐레이션 이미지 URL이 깨져 있다

## 증상

`lib/nearby-places-data.ts`의 나폴리 두 항목(`naples-panorama`, `naples-pizza`)과
베로나 한 항목(`verona-amarone`)은 실제 브라우저에서 이미지가 로드되지 않고
대체 표시("이미지를 불러올 수 없습니다")로 떨어진다. 기능 자체(항목 유지 +
대체 표시)는 의도한 대로 동작하지만, 실제 사진은 보이지 않는다.

## 관찰한 근거

- `next dev` 프리뷰에서 "도시 선택"을 나폴리로 바꾸면 두 항목 모두
  대체 표시가 뜨고, 베로나로 바꾸면 `리조토 알아마로네 맛집` 항목만
  대체 표시가 뜬다(2026-08-20 확인).
- 원인은 `commonsFilePath()`에 넘긴 Wikimedia Commons 파일명이 실제 파일과
  일치하지 않기 때문이다. 구현 시점에 `curl`로 여러 후보 파일명을 확인했으나
  Commons API 레이트리밋(429)에 자주 걸려 전체 40개 이미지를 다 검증하지
  못했다.

## 의심되는 원인

- 파일명 추측이 실제 Commons 업로드명(대소문자, 괄호, 연도 등)과 다름.

## 시도한 것

- `https://commons.wikimedia.org/wiki/Special:FilePath/<파일명>` 형태로
  다수의 후보 파일명을 `curl`로 검증했고, 나폴리·베로나 항목은 시도한
  후보가 모두 404였다(레이트리밋으로 추가 후보를 더 시도하지 못함).

## 다음 단계 제안

- Wikimedia Commons 검색(웹 UI 또는 API, 레이트리밋을 피해 요청 간 충분한
  간격을 두고)으로 나폴리 파노라마·피자, 베로나 아마로네 리조토 관련 실제
  파일명을 확인해 `lib/nearby-places-data.ts`의 해당 `imageUrl`을 교체한다.
- 스펙(`docs/specs/italy-travel-planner/spec.md`)의 가정에도 이미지 출처가
  "확정 필요"로 남아 있으므로, 이 기회에 전체 이미지 목록을 사용자와
  한 번에 확정하는 편이 효율적일 수 있다.
